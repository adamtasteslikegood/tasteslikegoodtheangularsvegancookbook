## Overview

Together these components provide a self-contained validation harness: the validation module implements read-only rules to determine whether Sprint 11 meets gating criteria, and the associated tests exercise those checks to ensure correctness and readiness. This directory's role in the larger system is to provide gating verification logic that can be run as part of sprint close processes or CI checks to prevent closing a sprint that does not meet the defined validation criteria.
