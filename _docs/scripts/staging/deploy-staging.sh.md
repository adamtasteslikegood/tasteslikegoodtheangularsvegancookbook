## Overview

This shell script deploys the staging Cloud Run services for the project by reusing production images from a specified Artifact Registry. It is intended to be run from the repository and defaults to a dry run mode unless invoked with --apply; it resolves an image tag (from an explicit --version or the package.json version), constructs image URIs, and prints a deployment plan. The script targets a dedicated staging GCP project and wires up required project-level resources and secrets before performing any changes.

The script performs preflight checks and idempotent setup for the staging project: enabling Secret Manager, validating and (in dry-run mode) guiding creation of required secrets such as FLASK_SECRET_KEY_STAGING and DATABASE_URL_STAGING, granting service accounts access to secrets, and preparing Cloud Run service account identities. It uses gcloud commands to inspect and mutate the staging project and wraps commands with a run_cmd helper that either echoes the command (dry run) or executes it (apply).

## Dependencies

- Bash with standard POSIX utilities such as `grep`

- Node.js, used to read the version from `package.json` when `--version` is omitted
