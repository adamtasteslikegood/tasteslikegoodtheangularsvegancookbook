## Overview

This module implements the Sprint 11 hard gate checks used to validate that Sprint 11 meets a set of read-only rules before the sprint close (or at charter time). It enforces that the Sprint 11 board exists and is active or closed, that every committed item is a sprint member, that no committed sprint member sits in the To Do status category (unless running the day-1 charter check), and that every committed SI has a rendered RCP acceptance story on the board. The script is intended to be run from the command line, supports a charter-only mode, can target specific issues, and returns distinct exit codes for pass, gate failure, and configuration/API errors.

## Architecture Notes

- Command-line interface implemented with argparse
- Integrates with an external Jira client (_jira_client.Jira) for read-only board and issue queries
- Explicit exit-code semantics for pass (0), gate failure (1), and configuration/API errors (2)
- Specialized charter mode that selectively skips rule 3 (To Do checks) for day-1 validation
- Error handling tied to a custom AtlassianGuardError exception

## Maintenance Notes
