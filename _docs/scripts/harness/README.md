## Overview

This directory holds the Sprint 11 "hard gate" validation script and its corresponding unit tests. At the root there are two Python modules: sprint11_hard_gate.py implements the Sprint 11 hard gate checks that validate a set of read-only rules to determine whether Sprint 11 meets gating criteria before sprint close or at charter time; test_sprint11_hard_gate.py contains unit tests that exercise the gate, with particular emphasis on the gate's "--charter" (day-1) mode. Together these files provide the implementation and verification for the sprint-level validation logic.

The purpose of this directory is to centralize the sprint validation harness for Sprint 11: the main module encapsulates the validation rules and run-time behavior, and the test module ensures correctness and guards against regressions, especially around charter/day-1 behavior. This directory is organized as a flat collection of related scripts and is intended to be used by developers who need to run or extend the Sprint 11 hard gate checks and by CI/test systems that execute the included unit tests.


### File Organization

Files are organized flat at the directory root: one implementation module (sprint11_hard_gate.py) and one test module (test_sprint11_hard_gate.py). This keeps the harness focused and easy to run or test without navigating subfolders.
