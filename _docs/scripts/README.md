## Overview

This directory is the central location for environment-focused automation scripts used to deploy and manage runtime services. At the root level there are no scripts in this snapshot; instead, all actionable deployment automation is grouped into a dedicated subdirectory for staging. The staging subdirectory contains a shell script that reuses production container images from an Artifact Registry to deploy the project's staging Cloud Run services.

The organization here cleanly separates environment-specific deployment logic (staging) from other repository concerns. The staging scripts are intended to use production images hosted in an Artifact Registry and automate deployment to Cloud Run for the staging environment. Together, the files in this directory implement deployment automation for the staging environment and serve as the entry point for developers/operators who need to recreate or update staging Cloud Run services using existing production images.


### File Organization

The directory uses a hierarchical layout: the root 'scripts' folder acts as a container for environment-specific subdirectories. Currently, all deployment automation is placed under staging/, keeping staging deployment scripts isolated from other environments or utilities that may be added later.
