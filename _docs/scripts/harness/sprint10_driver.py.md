## Overview

This module implements a command-line driver that enforces Sprint 10 PM rules by deciding whether individual SI tasks may be started. It reads a shared harness plan, inspects per-task controller state files, consults soak deadlines and Jira requirements, and produces a one-task controller plan for an allowed start. The driver leaves the controller implementation unchanged and only performs the pre-start eligibility checks and plan generation that allow the existing controller (loop_controller.py) to run a single task in isolation.

The file exposes functions to locate the shared state directory, load the harness plan, inspect task and controller state, compute soak deadlines, and enumerate reasons a task is refused. It also implements command handlers (status, start, soak, etc.), a CLI parser, and a main entry point to run the driver from the command line. Distinctive imports indicate it interacts with the Jira client, invokes subprocesses, and uses argparse for its CLI surface.
