## Overview

This directory holds three closely related Python modules that together implement and validate Sprint 10 product management enforcement logic. At the root level, sprint10_driver.py is a command-line driver that enforces Sprint 10 PM rules by deciding whether individual SI tasks may be started. The sprint10_hard_gate.py module implements the "hard gate" check used by the harness to verify a sprint and its committed items meet sprint-closing rules. The test_sprint10_driver.py module contains unit tests that exercise ordering, WIP limits, exact "Done" starts, and D6 capping behavior.

These components work together: the driver uses the hard-gate checks to make start/deny decisions for SI tasks, and the tests validate both the driver behavior and the gate logic. This directory acts as the enforcement and verification slice of the larger system that governs sprint start rules and sprint-closing constraints; it is intended to be used by developers and automation that need to validate or execute Sprint 10 start decisions and gating checks.


### File Organization

Files are organized at a single level in this directory: one executable driver (sprint10_driver.py), one enforcement/check module (sprint10_hard_gate.py), and one test module (test_sprint10_driver.py). This flat layout keeps the harness components together and makes it easy to run or test the driver and gate logic.
