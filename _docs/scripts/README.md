## Overview

This directory does not contain root-level script files; instead it organizes script-related code under a dedicated subdirectory. At the top level here there are no direct files to execute or edit. The primary work in this directory is grouped inside the harness/ subdirectory, which contains the Sprint 10 harness components responsible for deciding whether SI tasks may start and for enforcing sprint-closing hard-gate rules.

The harness/ subdirectory includes three closely related Python modules that together implement and validate Sprint 10 product management enforcement logic. The harness includes a command-line driver (sprint10_driver.py) that enforces Sprint 10 PM rules by deciding whether individual SI tasks may be started, supporting unit tests that validate that logic, and the enforcement components themselves. Together these pieces provide the scripts and tests used to evaluate and gate SI task starts as part of Sprint 10, making this directory the place to find and modify sprint-enforcement scripting and its tests.


### File Organization

Root of this directory contains no files; all script components are placed in the harness/ subdirectory to keep Sprint 10 enforcement code and its tests together. This keeps driver, enforcement logic, and tests co-located for easier development and review.
