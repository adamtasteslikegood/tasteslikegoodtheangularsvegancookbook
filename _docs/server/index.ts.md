## Overview

This module is the entry point for the server-side runtime. It wires together an Express-based HTTP surface with supporting pieces imported from local modules: a Flask proxy, AI validation, a Valkey client, and a route classification utility. The file exposes two top-level functions: ready, which prepares and starts the server and composes the imported pieces into a running service, and gracefulShutdown, an asynchronous routine that tears down the running server and performs any Valkey-specific shutdown work.

The implementation centers on composition of independent factories and utilities: createFlaskProxy, createAiValidation, createValkeyClient, shutdownValkey, and classifyRoute. The module-level functions coordinate those components and depend on Node standard helpers (path and fileURLToPath) and the Express framework to expose HTTP behavior and lifecycle management (including an async graceful shutdown that closes the Server and cleans up the Valkey client).
